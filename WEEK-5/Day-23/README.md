# Day 23 - Cybersecurity internship

## Research Topic

* Studied how browser keyboard shortcuts can be abused to bypass certain restrictions on `javascript:` URLs.
* Learned how seemingly low-impact vulnerabilities such as Open Redirects and Stored XSS can be chained into more severe attacks.
* Researched Clickjacking techniques using invisible iframes and user interaction tricks.
* Analyzed real-world bug bounty reports involving Microsoft and Wix.

## Practical Learning

* Explored how Stored XSS vulnerabilities arise from insufficient URL validation.
* Understood the importance of server-side input validation and Clickjacking protections.
* Learned how attackers may combine multiple weaknesses to increase impact.

## Live Target Practice

* Focused on testing live targets within authorized scope.
* Practiced identifying user-controlled URL parameters and input fields.
* Tested for common web vulnerabilities such as:

  * Open Redirect
  * Stored XSS
  * URL Validation Issues
  * Clickjacking Misconfigurations
* Improved methodology for analyzing real-world web applications and bug bounty targets.

## Key Takeaway

Small vulnerabilities should not be ignored, as chaining multiple issues together can lead to significant security impact. Always investigate the complete attack path rather than evaluating findings in isolation.
