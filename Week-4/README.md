# Week 4 - Cyber Security Internship

## Overview

Week 3 focused on advancing vulnerability research, bug bounty methodology, CVE analysis, and practical web application security testing. The objective was to strengthen understanding of real-world security issues while continuing the study of selected vulnerability categories from the OWASP Top 10 and bug bounty programs.

---

## Learning Activities

### 1. Mastering Vulnerability Categories

Continued research and study of selected vulnerability classes, including:

* Business Logic Vulnerabilities
* Cryptographic Failures
* Server-Side Request Forgery (SSRF)
* Authentication and Authorization Issues
* API Security Misconfigurations

Focused on understanding:

* Root causes
* Exploitation techniques
* Impact assessment
* Mitigation strategies
* Real-world case studies

---

### 2. CVE Analysis

Reviewed and analyzed publicly disclosed CVEs to understand:

* Vulnerability descriptions
* Affected software versions
* Attack vectors
* Security impact
* Vendor remediation approaches

This activity improved vulnerability assessment and risk evaluation skills.

---

### 3. Bug Bounty Writeup Analysis

Studied bug bounty reports from security researchers to learn:

* Reconnaissance methodologies
* Vulnerability discovery processes
* Proof-of-Concept (PoC) development
* Responsible disclosure practices
* Report writing techniques

The focus was on understanding how vulnerabilities are identified and documented in real-world applications.

---

### 4. P4 Severity Bug Research

Researched P4 (Low Severity) vulnerabilities to understand:

* Security misconfigurations
* Information disclosure issues
* Weak security practices
* Low-impact findings commonly accepted in bug bounty programs

Learned how even low-severity issues can contribute to larger attack chains.

---

## Practical Activities

### JavaScript Reconnaissance

Performed analysis of JavaScript files obtained from target applications to identify:

* Hidden routes and application paths
* Payment-related functionality
* API endpoints
* Third-party integrations
* Client-side security observations

Examples of findings included:

* Payment-related routes
* Juspay payment integration references
* Observability and logging endpoints
* Frontend component identifiers
* Application feature mappings

### Business Logic Vulnerability Research

Studied business logic flaws and reviewed practical examples to understand:

* Workflow manipulation
* Authorization bypass scenarios
* Application trust assumptions
* Abuse of intended functionality

### Source Code Review

Continued reviewing JavaScript assets and application resources to improve:

* Attack surface mapping
* Feature enumeration
* Endpoint discovery
* Security-focused reconnaissance techniques

---

## Weekly Outcome

Successfully expanded practical understanding of web application security by combining theoretical research with hands-on reconnaissance and vulnerability analysis. Continued progress was made toward mastering selected vulnerability categories while improving bug bounty hunting and security assessment skills.
