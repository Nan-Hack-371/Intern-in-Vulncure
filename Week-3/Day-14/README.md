# Day 14 – Mastering Bugs & Vulnerability Research

## Overview

Day 14 focused on expanding practical vulnerability research skills through CVE analysis, bug bounty writeups, and business logic vulnerability studies. The objective was to strengthen the understanding of real-world attack scenarios while improving vulnerability documentation and reporting techniques.

## Tasks Completed

### 1. CVE Research & Writeups

* Analyzed multiple publicly disclosed CVEs.
* Studied vulnerability root causes and exploitation methods.
* Documented technical details, impact, affected systems, and mitigation strategies.
* Improved understanding of vulnerability disclosure and security advisories.

### 2. P4 Severity Bug Bounty Writeup

* Reviewed a low-severity (P4) bug bounty report.
* Analyzed the vulnerability identification process.
* Studied proof-of-concept (PoC) development and report structure.
* Learned how small security issues can contribute to overall application security risks.

### 3. Business Logic Vulnerability Study

* Explored business logic flaws and their impact on application security.
* Learned how attackers exploit flawed assumptions in workflows and user behavior.
* Studied common examples such as:

  * Authentication bypass scenarios
  * Workflow manipulation
  * Access control logic issues
  * Price and discount manipulation

### 4. Exploitation Techniques Learning

* Continued the "Mastering Bugs" learning path.
* Studied practical exploitation methodologies used by security researchers.
* Focused on vulnerability discovery, validation, and responsible reporting practices.
* Improved understanding of how attackers chain weaknesses to achieve greater impact.
